# mini_project3

Student Records and Marks Analyzer

📌 About This Project
Build a terminal-based student records manager that stores student details and subject marks using Python data
structures. The program should accept records from the user, calculate each student's total and average, assign a result
category, and provide simple class-level summaries such as unique subjects and students who passed. This project
practises lists, tuples, sets, and dictionaries together in one backend program.

⭐ Future Improvements
Add multiple student records.
Store unique student IDs and student details.
Record marks for three subjects.
Validate student IDs and marks.
Calculate total marks and average.
Assign result categories automatically.
Display all student records.

📚 Data Structures Used
Data Structure	Purpose
List	Store student IDs and subject marks
Tuple	Store fixed subject names
Set	Find unique and passed subjects
Dictionary	Store student records and details
